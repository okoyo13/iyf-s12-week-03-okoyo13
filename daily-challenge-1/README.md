# Daily Challenge 1

A simple web project created using terminal commands.

## Project Structure

- `src/index.html` - Main webpage
- `src/css/style.css` - Stylesheet
- `src/js/app.js` - JavaScript file
- `about.html` - Generated HTML example
- `boilerplate.ps1` - Script to generate HTML boilerplate

## How to Run

Open `src/index.html` in a web browser.
